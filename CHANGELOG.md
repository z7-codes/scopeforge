# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-11-23

- Replaced the older ScopeForge CLI with the UX-first DorkLens workflow.
- Added `point it, and it sees` branding, wizard, profiles, doctor, selftest, and offline demo.
- Added SQLite-backed staged pipeline: passive, dork, dirs, params, payload, blind, report.
- Added scope gate, per-host token bucket, GET-only requests, and no redirect following.
- Added baseline-twice detection with regex, length, status, reflection, similarity, and location signals.
- Added soft-404 calibration, unstable-page threshold bump, and per-finding next-step advice.
- Added HTML, Markdown, and JSON reports plus `report --open`.
- Added `dorklens.yaml.example`, `install.sh`, `PLAN.md`, and professional GitHub workflows.

## 0.x — ScopeForge legacy

- Earlier versions provided passive exposure worksheets, benign marker probes, evidence analysis, and scoped dork planning.
